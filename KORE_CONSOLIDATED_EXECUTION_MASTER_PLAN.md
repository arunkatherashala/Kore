#### 2. Security Controls (security.tf)
```
Automated Security:
├─ GuardDuty threat detection
├─ Security Hub (compliance aggregation)
├─ AWS Config (compliance tracking)
└─ Systems Manager (keyless access)

Compliance Rules:
✓ Encrypted volumes
✓ MFA enabled
✓ No admin access policies
✓ Tagging enforcement
```

#### 3. Encryption (encryption.tf)
```
Encryption Implementation:
├─ KMS master key (auto-rotated)
├─ RDS encryption (AES-256)
├─ S3 encryption (AES-256)
├─ EBS encryption (automatic)
└─ TLS 1.3 (data in transit)

Key Management:
✓ Centralized KMS
✓ Auto key rotation
✓ Access logging
✓ Key policy enforcement
```

#### 4. Monitoring & Logging (monitoring.tf)
```
Audit Trail:
├─ CloudTrail (all API calls, 7-year retention)
├─ VPC Flow Logs (network traffic, 7-year retention)
├─ CloudWatch Logs (application, 7-year retention)
├─ EventBridge (real-time alerts)
└─ Security Hub (compliance dashboard)

Alerting:
✓ Failed login attempts (>5 = alert)
✓ Unauthorized API calls (any = alert)
✓ Privilege escalation (any = alert)
✓ Data access (monitored)
```

#### 5. Access Control (iam.tf)
```
Zero Trust Model:
├─ MFA enforcement (required for all)
├─ Admin role with MFA (assumption required)
├─ Developer role (least privilege)
├─ Service accounts (credential rotation)
└─ Password policy (14+ chars, expire 90 days)

Segregation of Duties:
✓ Admin role: Infrastructure only
✓ Developer role: Application only
✓ Security role: Audit only
✓ No cross-role access
```
