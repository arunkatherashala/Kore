Format Compression Ratio vs KORE Use Case
KORE 56.4% Baseline 🏆 Best Balanced
ORC 58.3% +1.9% (worse) Hive Ecosystem
Parquet 46.2% -10.2% (better) Max Compression

Key Insight

KORE outperforms ORC on mixed analytics data while maintaining faster decompression than Parquet. The smart fallback strategy prevents data expansion on incompressible data, making it ideal for production workloads.

Getting Started

Installation

Python

pip install kore-fileformat

JavaScript / Node.js

npm install kore-fileformat

Java / Maven

<dependency>
    <groupId>com.kore</groupId>
    <artifactId>kore-fileformat</artifactId>
    <version>1.2.2</version>
</dependency>

Docker

docker pull ghcr.io/arunkatherashala/kore:latest
