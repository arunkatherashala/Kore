### **STEP 2: Deploy Automated Data Collection** ⏱️ (10 minutes)

**File to use:**
- `KORE_ANALYTICS_AUTOMATION.gs` - 400-line automation script

**How to deploy:**

1. **Open your Google Sheet** "KORE Global Analytics Dashboard"

2. **Go to Apps Script:**
   ```
   Extensions → Apps Script
   ```

3. **Copy automation code:**
   ```
   - Delete default code
   - Copy all 400 lines from KORE_ANALYTICS_AUTOMATION.gs
   - Paste into the script editor
   ```

4. **Find your Sheet ID:**
   ```
   In URL: docs.google.com/spreadsheets/d/[SHEET_ID]/edit
   Copy the long ID between /d/ and /edit
   ```

5. **Update SHEET_ID in code:**
   ```
   Find line: const SHEET_ID = "YOUR_SHEET_ID_HERE";
   Replace with your actual Sheet ID
   Save ✅
   ```

6. **Run setup (one time only):**
   ```
   Function: setupSchedules()
   Click ▶️ Run
   
   This creates 3 automatic triggers:
   • Hourly: Update download metrics
   • Every 6 hours: Update active users
   • Weekly (Sunday 8 AM): Send email report
   ```

7. **Authorize:**
   ```
   Google will ask for permissions
   Click "Review permissions"
   Click "Allow" for Google Sheets access
   ✅ Done!
   ```

**Result:** Dashboard updates automatically every hour ✅
